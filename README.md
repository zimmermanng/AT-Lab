# AT-Lab
Dokumentation von Assistiven Technologien fürs Studium

Dieses Repo dokumentiert Assistive Technologien, die beim Studium unterstützen können. Es wird von Studierenden der Hochschule der Medien in Stuttgart im Rahmen der Lehrveranstaltung AT-Lab gepflegt. 

Es dürfen sich auch andere Hochschulen an diesem Repo beteiligen. Kontaktieren Sie uns gerne.

Wir bemühen uns um Korrektheit und Aktualität dieses Repos. Trotzdem kann es passieren, dass Informationen falsch, unvollständig oder veraltet sind. Gerne können Sie uns in diesem Fall kontaktieren.

Alle Inhalte sind unter der CC-BY 4.0 Lizenz freigegeben.
